# PetFlow

Projeto de site e ferramenta simples de organização para o pet shop **Amigos de Patas Banho e Tosa**.

## Objetivo

Ajudar um pequeno negócio a organizar os agendamentos e facilitar para os clientes encontrar os serviços e solicitar um horário. O MVP deve ser simples de usar, funcionar bem no celular e reduzir a dependência de organizar tudo manualmente pelo WhatsApp.

## Negócio atendido

- Nome: Amigos de Patas Banho e Tosa
- Instagram: [@amigos_de_patas_banho_e_tosa](https://www.instagram.com/amigos_de_patas_banho_e_tosa/)
- Serviços informados: banho, tosa e hidratação
- Equipe: uma pessoa
- Organização atual: WhatsApp
- Prioridade: presença para clientes e organização interna
- Endereço informado no perfil: Rua Humaitá, nº 110. A cidade ainda precisa ser confirmada antes de publicar o endereço no site.

## Escopo inicial do MVP

### Site para clientes
- Apresentar o pet shop e os serviços.
- Exibir contato e localização somente após confirmar os dados.
- Permitir solicitar um agendamento com serviço, data/horário e dados básicos do cliente e do pet.
- Oferecer contato pelo WhatsApp como alternativa clara.

### Organização interna
- Visualizar solicitações/agendamentos.
- Manter o processo adequado para uma operação de uma pessoa.
- Evitar automações complexas e custos recorrentes no primeiro protótipo.

## Identidade visual

Usar como referência a identidade já existente do negócio: logotipo colorido, ilustrações de cães, gatos e patas, com tons de rosa, amarelo e roxo. O site deve parecer acolhedor e profissional, com boa leitura no celular. Não inventar depoimentos, preços, horários de funcionamento, endereço completo ou políticas.

## Diretrizes de trabalho

1. Manter o escopo pequeno e adequado a um negócio com uma pessoa.
2. Priorizar uso pelo celular e textos simples.
3. Não publicar alterações sem revisão do usuário.
4. Não adicionar serviços, informações comerciais ou dados de contato sem confirmação.
5. Não incluir chaves, senhas ou dados pessoais sensíveis no repositório.
